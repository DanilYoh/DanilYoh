## Engineering priorities

- turn product requirements into maintainable component boundaries;
- keep data fetching, state, and presentation responsibilities explicit;
- validate untrusted data and handle loading, empty, and failure states;
- automate linting, type-checking, tests, and production builds;
- measure quality through user-visible behavior, not framework checklists.
